# Ballygunge Pandal Trail

Build a complete, polished website called “BALLYGUNGE PANDAL TRAIL 2026” in the same premium maximalist design language as my previous Salt Lake Pandal Trail: vivid jewel colors, editorial typography, alpona/lotus-inspired motifs, playful but accessible motion, layered cards, thick ink borders, responsive/mobile-first layout. It must be its own separate website/project, not edit the Salt Lake site. Main goal: a practical, interactive South Kolkata Durga Puja pandal-hopping guide centered on Ballygunge and the adjacent Gariahat / Lake Road area.

Use this curated main circuit, with the listed addresses and map-search URLs. Don't make unsupported claims about exact walking distances/times; suggested order is crowd-dependent and barricades can change routes:
1. Ekdalia Evergreen Club — 15, Ekdalia Road, Ekdalia, Ballygunge, Kolkata 700019. Known for traditional idol and temple-inspired pandal architecture. Google Maps query “Ekdalia Evergreen Club Durga Puja Kolkata”.
2. Singhi Park Sarbojanin — 18/33, Dover Lane / Ramani Chatterjee Road, Ballygunge, Kolkata 700029. Known South Kolkata stop for detailed pandal presentation and lighting. Maps query “Singhi Park Sarbojanin Durga Puja Kolkata”.
3. Hindusthan Park Sarbojanin — Hindustan Park, Ballygunge, off Rashbehari Avenue, Kolkata. Exact gate/address should be confirmed on Maps. Maps query “Hindusthan Park Sarbojanin Durga Puja Kolkata”.
4. Ballygunge Cultural Association — 20, Lake View Road, Lake Terrace, Kolkata 700029. Reported 2026 theme “Jojon” (যোজন; connection), but label “reported theme — verify onsite”. Maps query “Ballygunge Cultural Association Durga Puja Kolkata”.
5. Samaj Sebi Sangha — 24A, Lake View Road, Hemanta Mukherjee Sarani, Lake Terrace, Ballygunge, Kolkata 700029. Maps query “Samaj Sebi Sangha Durga Puja Kolkata”.
6. Ballygunge 21 Pally — 17, Bondel Road, near Patha Bhavan, Ballygunge Park, Kolkata 700019. Maps query “Ballygunge 21 Pally Durga Puja Kolkata”.
7. Maddox Square — Garcha, Ballygunge, Kolkata 700026. Maps query “Maddox Square Durga Puja Kolkata”. This is a classic open-park, traditional idol / community adda stop.
8. Hindusthan Club — 37/B, Hindustan Road, Dover Terrace, Ballygunge, Kolkata 700019. Maps query “Hindusthan Club Durga Puja Kolkata”.
Optional add-on: 71 Palli Baishakhi Sarbojanin Durgotsav Samity — 7, Moni Mukherjee Road, Ballygunge Gardens, Kolkata 700019. Maps query “71 Palli Baishakhi Sarbojanin Durga Puja Kolkata”.
If descriptions/addresses are uncertain, explicitly flag “verify exact gate on Maps”; no invented timings, phone numbers, tickets, or theme claims. Distinguish the main circuit and optional add-on.

Features: (1) bold hero with “8 iconic stops / 1 South Kolkata trail” and CTAs; (2) interactive pandal cards with short descriptions, area/address, “Open Maps” and “Get directions” links using Google Maps search/dir URLs, and visited toggles; (3) checklist/progress persisted in localStorage; (4) route grouping/route selector between “Classic Ballygunge loop” and “Extended South Kolkata”; (5) search by name/area and filter All / To visit / Visited; (6) copy/share itinerary button with Web Share API and clipboard fallback; (7) packing checklist and useful crowd-safety tips; (8) mobile-friendly navigation, reduced-motion support, keyboard accessibility; (9) footer says independent visitor guide, not affiliated with committees, and map/address details may change due to Puja traffic/barricades; (10) update document title, meta description and all content; no Salt Lake-specific remnants.
